# Quiz App — Servlets + JDBC + MySQL

A small web-based quiz application built with raw Java Servlets (no Spring), an embedded Jetty server, and JDBC against MySQL. The quiz contains 10 general-knowledge/science questions and stores attempts in MySQL.

## How it works

- `Main` boots the embedded Jetty server and registers four servlets; no external Tomcat server is required.
- `DBInitializer` creates the `questions` and `results` tables if they do not exist and seeds 10 questions when the questions table is empty.
- `QuestionDAO` and `ResultDAO` use JDBC with prepared statements.
- Flow: `/` → `/quiz` → `/submit` → `/leaderboard`.

## Requirements

- Java 17+
- Maven 3.9+
- MySQL 8+

## Run locally from Eclipse

### 1. Start MySQL

You can use XAMPP, MySQL Community Server, or Docker:

```bash
docker run --name quiz-mysql -e MYSQL_ROOT_PASSWORD=root -e MYSQL_DATABASE=quizapp -p 3306:3306 -d mysql:8
```

### 2. Create the database

The application creates its tables automatically, but the database itself must exist:

```sql
CREATE DATABASE quizapp;
```

### 3. Configure database credentials

The application reads:

- `JDBC_URL`
- `DB_USER`
- `DB_PASSWORD`

Local defaults are:

```text
JDBC_URL=jdbc:mysql://localhost:3306/quizapp?useSSL=false&allowPublicKeyRetrieval=true&serverTimezone=UTC
DB_USER=root
DB_PASSWORD=
```

If your MySQL installation uses another username/password, set these as Eclipse environment variables in the Run Configuration. Do not commit real passwords to GitHub.

### 4. Import into Eclipse

Use:

`File → Import → Maven → Existing Maven Projects`

Select the folder containing `pom.xml`.

Make sure Eclipse uses JDK 17 or newer.

### 5. Run

Open:

`src/main/java/com/quizapp/Main.java`

Right-click → `Run As → Java Application`.

Expected console output:

```text
Initializing database...
Database ready.
Quiz app running on port 8080
```

Open:

`http://localhost:8080`

## Deploy to Render with MySQL

This repository is configured to deploy the Java application and a MySQL 8 private service on Render.

The `render.yaml` creates:

1. `quizapp-mysql` — MySQL 8 private service with a persistent disk.
2. `quizapp` — Java 17/Jetty web service built from `Dockerfile`.

The web service receives these variables automatically:

```text
JDBC_URL
DB_USER
DB_PASSWORD
```

The MySQL password is generated by Render and is not stored in the repository.

### Deploy

1. Push this repository to GitHub.
2. In Render choose `New → Blueprint`.
3. Select the GitHub repository.
4. Review the two services before applying.
5. Deploy.
6. Check the MySQL service is healthy before troubleshooting the Java service.
7. Open the public URL of the `quizapp` web service.

The Java application reads Render's `PORT` environment variable automatically.

## Important notes

- There is no authentication; anyone who can access the app can submit a score.
- The server currently opens a JDBC connection per DAO operation. For larger traffic, use a connection pool such as HikariCP.
- The quiz is intentionally simple and stores questions in MySQL.
- `target/` and local Eclipse metadata are ignored by Git and should not be committed.
